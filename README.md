# Grovio SuperMart

A multi-app Flutter project for Grovio SuperMart (Customer, Store Manager, and Driver).

## iOS Automated Build (GitHub Actions)

Since iOS builds require macOS, this repository includes an automated GitHub Actions workflow to build the iOS app (`.ipa` and `.app.zip`) on GitHub's cloud macOS runners:

1. Push your code or go to the **Actions** tab on your GitHub repository.
2. Select **Build iOS App (iPhone)** and click **Run workflow**.
3. Once completed, download `Grovio-SuperMart-iOS-App` from the Artifacts section.
4. Install the `.ipa` or `.app` on your iPhone using **AltStore**, **Sideloadly**, **TrollStore**, or **TestFlight**.
